## Responsive implementation contract

- Desktop uses one stable left content pane and a right Map/Route workspace at an initial 64/36 split. The keyboard/pointer divider is adjustable, and collapsing/restoring the map does not change the selected content view.
- Tablet landscape uses the same shell at 56/44. Overview does not horizontally scroll; Table scrolls internally.
- Tablet portrait and mobile render the selected content full width. A 44px header Map control opens Map & routes in a high/full-height focus-trapped Sheet; no floating control covers the last itinerary rows.
- Mobile Table remains a semantic Matrix. Day/Date is the 96px sticky first column; the Day-only column is hidden at this breakpoint and horizontal movement stays inside the Matrix scroller.
- Overview remains time-agnostic and ordered by saved manual order. Optional real time labels may appear inline only when the owner shares times.
- Overview and Timeline render each day with one deduplicated City route in the header and omit City rows from the main content. Overview consolidates Activities, Meals, Transport, independent Car rental, and closing Hotel groups. Timeline deliberately uses a distinct Activity-only connected rail with richer enabled Activity details and a closing Hotel endpoint connected directly after its final Activity; Transport, Meals, independent Car rental, and notes stay outside the rail as concise support groups. This is a user-directed refinement of the supporting Timeline anatomy, not a new Stitch canonical screen.
- Content selection and map selection are viewer-local and bidirectional. Explicit click or Enter/Space activation focuses day markers; hover/focus alone does not. A marker click scrolls/focuses the related content while Whole trip marker selection preserves Whole trip scope.
- Whole trip uses the owner Overview route model and explicit calculation. Day route defaults to all placed shared eligible stops, keeps unplaced Activities visibly disabled instead of dropping them, locks the previous day's last Hotel as start and today's last Hotel as end when present, exposes Drive/Transit/Bike/Walk with visible labels, and never uses drag-and-drop.
