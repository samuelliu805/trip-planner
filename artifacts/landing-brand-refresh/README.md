The landing now leads with a concise readiness promise and an earlier, more spacious version of the Paris travel desk motion, followed by the route story, departure chapter, and responsive planning-to-journal preview. All screenshots were captured from the local Global production build in Chromium. The two WebM files contain successive browser captures encoded locally with GStreamer at 12fps (8 seconds for the hero, 3 seconds for sharing); no external animation assets or new dependencies were added.
